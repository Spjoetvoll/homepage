# Sysopoly Homepage

Personal portfolio website for **Morten Spjotvoll** — Software Architect from Norway.

## Tech Stack

- React 19 + TypeScript
- Vite
- CSS Modules with design tokens
- i18next (English/Norwegian)
- EmailJS for contact form

## Development

```bash
npm install
npm run dev
```

## Environment Variables

Copy `.env.example` to `.env` and fill in your EmailJS credentials for the contact form.

## Build

```bash
npm run build
```
